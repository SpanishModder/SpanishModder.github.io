About

Relievo is a free tool that generates height maps from open elevation data, for personal, educational, or professional use (including terrain design, video games, 3D printing, and more).

Data Sources

Elevation data is provided through AWS Open Data (Terrain Tiles), derived from public datasets such as SRTM, 3DEP, and GMTED. Base map data is provided by OpenStreetMap and its contributors, under the ODbL license.

Use of Generated Height Maps

The PNG file you download is yours to use freely in your projects. Please note that the accuracy of the underlying data varies by location and should not be considered a substitute for a professional land survey.
