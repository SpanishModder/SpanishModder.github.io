    Height maps from real elevation data

    A height map is a grayscale image where each pixel represents an elevation: black marks the lowest point in the area and white the highest. Game engines such as Unity and Unreal Engine, and terrain generation tools such as World Machine or Gaea, use it as input to build 3D terrain meshes.

    Relievo generates these maps from real elevation data for any point on the planet, combining different open topographic data sources. This means the height map you download is not procedural noise: it represents the mountains, valleys, and coastlines that actually exist in the location you selected.

    All processing — from decoding the elevation tiles to rendering the preview — takes place in your browser. There is no need to create an account or install anything, and your selections are not stored on any server.
